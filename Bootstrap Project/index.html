Bevezetés

A Bootstrap egy hatékony, funkciókban gazdag frontend eszköztár: előre elkészített stílusokkal és komponensekkel gyorsabban építhetsz reszponzív weboldalakat.

Mi az a Bootstrap?

A Bootstrap CSS-osztályokat és JavaScript-komponenseket ad (navbar, collapse, offcanvas, modal stb.). A kinézet nagy része osztályokkal áll össze; egyes komponensekhez a JS bundle is kell.

Gyors kezdés

Három lépés a hivatalos Get started nyomán:

  1. Hozz létre egy HTML-fájlt (DOCTYPE, lang, viewport).
  2. Töltsd be a Bootstrap CSS-t a <head>-ben (CDN + integrity).
  3. A </body> előtt add hozzá a bootstrap.bundle.min.js fájlt (Popper benne van).
<h1>Helló, világ!</h1>

Fontos globális beállítások

A Bootstrap a Reboot réteggel egységesíti az alapstílusokat, és globálisan box-sizing: border-box-ot állít be. Így a szélesség a paddingot és a keretet is tartalmazza — kiszámíthatóbb a layout. A saját CSS/style.css a Bootstrap CSS után töltődik be, ezért tudsz felülírni.

JavaScript-komponensek

A felső menü hamburger gombja data-bs-toggle="collapse" és data-bs-target="#foMenu" párossal működik: a target a id="foMenu" elemre mutat. Ugyanez a minta később offcanvashez és modalhoz is kell.

Ismerkedés a Bootsrappel

A Bootstrap egy ingyenes és nyílt forráskódú frontend keretrendszer. Segítségével gyorsan készíthetünk reszponzív weboldalakat.

Mi az a Bootstrap?

A Bootstrap előre elkészített CSS osztályokat és JavaScript komponeneseket biztosít a webfejlesztők számára.

Gyors kezdés

A Bootstrap használatához először be kell töltenünk a szükséges CSS és JavaScript fájlokat.

<h1>Helló Bootstrap!</h1>

Miért használjunk Bootstrapet?

A Bootstrap haszálatával leegyszerűsödik a Weblap készítés.
